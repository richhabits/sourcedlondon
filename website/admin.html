One-Time Setup

Connect your services.

This runs once per deployment. Nothing here is shared with anyone else who buys this template — every copy of the site talks to its own backend.

1

Create a free Supabase project

At supabase.com → New Project (free tier). Takes ~2 minutes to spin up.

2

Run the schema

In your project's SQL Editor, paste and run everything in supabase/schema.sql from this project folder.

3

Paste your project keys

Project Settings → API → copy the Project URL and anon public key below.

4

Make yourself an admin

Sign up for an account on the live site's account.html page first, then in Supabase's SQL Editor run:

insert into admin_users (id) select id from auth.users where email = 'you@example.com';

5

Optional: turn on payments, AI & reg lookup

See SETUP.md for the three Edge Functions (Stripe checkout, AI assistant, DVLA/MOT lookup) — each is a couple of terminal commands, all free to run at this scale.

Admin

Sign in.

No account yet? Create one on account.html, then ask an existing admin to add you (see Setup step 4).
